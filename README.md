# JPEG Decoder (C++20)

Чистая реализация декодера изображений формата JPEG (Baseline Sequential, SOF0) на C++20 с нуля.

**Ключевые возможности:**
- Полный разбор маркеров JPEG (SOI, SOF0, DHT, DQT, SOS).
- Декодирование таблиц Хаффмана и побитовое чтение потока (DC/AC).
- Полный конвейер обработки: зигзаг-обход, деаквантование, IDCT и преобразование YCbCr → RGB.
- Устойчивость к некорректным файлам: валидация входных данных и обработка ошибок через исключения.

**100% без внешних зависимостей (кроме Catch2 для тестов)** — ни OpenCV, ни libjpeg, только чистый C++17 и STL. Проект создан как учебный пет-проект для глубокого понимания внутреннего устройства JPEG.
