# JPEG Decoder (C++20)

Учебный пет-проект: реализация декодера JPEG (Baseline Sequential) на C++17 с нуля.

## Возможности
- Разбор основных маркеров (SOI, SOF0, DHT, DQT, SOS).
- Декодирование Хаффмана (DC/AC).
- Полный цикл: извлечение коэффициентов, зигзаг, деаквантование, IDCT, YCbCr → RGB.
- Валидация входных данных, обработка ошибок через исключения.
